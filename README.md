## 自动更新

修改并提交 `main` 分支后，GitHub Pages 会自动重新发布入口页面。课程主页面由 Netlify 托管，课程内容更新后在 Netlify 发布即可通过入口访问最新版本。GitHub Pages 本身提供静态页面，不运行账号后台或服务器端数据库。

本仓库只包含公开入口页面，不包含原始学习文档、账号密码、Cookie、数据库密钥或个人学习记录。
